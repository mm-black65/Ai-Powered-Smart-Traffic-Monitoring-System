2. grayscale image contains one number per pixel.
200 210 220

150 100 80

20 10 0

Each value tells how bright the pixel is.

3. Color Images

Color images contain three numbers per pixel.
We have

(Blue, Green, Red)

Example

(255,0,0)
In OpenCV this means

Blue

Not red!

This surprises many beginners.

OpenCV uses

BGR

NOT

RGB
